TEKNİK KARARTECHNICAL DECISION

Kaynağı korumak, doğruyu garanti etmek değilPreserving sources does not guarantee truth

Hafızadaki özetin özgün kaynağına dönülebilmesi gerekiyor. SQLite katmanı kaynak baytlarını ve referanslarını saklıyor, SHA-256 ile bütünlüğü kontrol ediyor. Bu kontrol içeriğin değişip değişmediğiyle ilgili; kaynağın veya özetin doğru olduğunu kanıtlamıyor.A memory summary needs a path back to its original source. The SQLite layer stores source bytes and references and checks integrity with SHA-256. This checks for content changes; it does not prove the source or summary is true.
