[ 01 ]

Phase 1 · Olaylar ve LLM GatewayPhase 1 · Events and LLM Gateway

Asenkron Event Bus bileşenler arasında olay taşır. Sağlayıcıdan bağımsız Gateway, dar kapsamlı bir OpenAI uyumlu metin adaptörüyle model çağrılarını yönetir. Mevcut adaptör streaming, çoklu ortam, otomatik tekrar veya yedek sağlayıcı içermez.An asynchronous Event Bus connects components. A provider-neutral Gateway handles model calls through a narrow OpenAI-compatible text adapter. The adapter has no streaming, multimodal support, automatic retries or fallback providers.

[ 02 ]

R1 · Kararın biçimiR1 · Decision contracts

Modelin çıktısı son yanıt veya araç önerisi olarak katı JSON kurallarıyla ayrıştırılır. Boyut, derinlik ve alan biçimi kontrol edilir. Doğru biçimli bir araç önerisi, o araca erişim izni anlamına gelmez.Model output is parsed as a final answer or tool proposal using strict JSON rules. Size, depth and fields are checked. A correctly shaped tool proposal does not grant permission to execute it.

[ 03 ]

R2 · İzin kontrollü hafıza okumasıR2 · Permission-controlled memory reads

memory.read için görev kapsamı, araç izni ve kayıt kimliği eşleşmelidir. Model sağlayıcısına aktarım ayrıca açık aktarım izni ve yapılandırılmış hedefle eşleşme gerektirir. Yerel okuma yetkisi tek başına dışarı aktarım yetkisi değildir.memory.read requires matching task scope, tool permission and record ID. Provider disclosure also requires an explicit export grant and a matching configured destination. Local read access alone does not permit disclosure.

[ 04 ]

R3 · Sınırlı yürütme döngüsüR3 · Bounded execution loop

Gateway, Event Bus ve salt okunur hafıza aracı aynı döngüde birleştirildi. Varsayılan sınırlar 3 model çağrısı, 2 araç denemesi ve 30 saniyedir. Araç çıktıları güvenilmeyen veri olarak işlenir; izinler modelden bağımsız denetlenir.The Gateway, Event Bus and read-only memory tool are combined in one loop. Defaults are 3 model calls, 2 tool attempts and 30 seconds. Tool output is treated as untrusted data; permissions are checked independently of the model.

[ 05 ]

Bugünkü sınırlar ve sıradaki adımCurrent limits and next step

R3 uygulandı; bağımsız güvenlik incelemesi bekleniyor. Doğrulama için çevrimdışı testler kullanılıyor. Runtime shell çalıştırmaz, belleğe yazmaz ve arka planda özerk görev zamanlamaz. Senkron SQLite işlemleri zorla kesilemez; zaman sınırları işbirliklidir.R3 is implemented and awaits independent security review. Verification uses offline tests. The runtime does not execute a shell, write memory or schedule autonomous background tasks. Synchronous SQLite operations cannot be forcibly interrupted; deadlines are cooperative.

[ 06 ]

Sonraki katmanlarNext layers

Projeye özel bilgi erişimi, bağlam oluşturma ve bilgisayar–edge–gömülü cihaz koordinasyonu yol haritasında. Core, Edge, Device ve Client yapısı hedef mimaridir; tüm cihazların bugün birbirine bağlı olduğu anlamına gelmez.Project-aware retrieval, context building and coordination across computers, edge and embedded devices remain on the roadmap. Core, Edge, Device and Client describe the target architecture, not a claim that every device is connected today.
