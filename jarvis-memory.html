JARVIS — Hafıza ve KaynaklarJARVIS — Memory and Provenance

Bir bilginin kendisi kadar kaynağını, kapsamını ve hangi kararın yerini aldığını koruyan hafıza katmanı.A memory layer that preserves provenance, scope and decision history alongside information.

← JARVIS genel bakışJARVIS overview

[ KISA SÖZLÜKQUICK GLOSSARY ]

Önce iki temel kavram.Two concepts to start with.

KapsamScope

Bir bilginin hangi proje veya görevle ilişkili olduğu.The project or task to which information belongs.

Kaynak referansıSource reference

Özetin dayandığı özgün içeriği işaret eden kayıt.A pointer to the original content behind a summary.

[ 01 ]

C0 · Bağlam sözleşmeleriC0 · Context contracts

Bilgi; görev kapsamı, kaynak referansı, özet ve kritik olgularla temsil edilir. Sözleşmeler bileşenlerin aynı veri biçimiyle çalışmasını sağlar; kendi başlarına kullanıcı kimliğini doğrulamaz.Information is represented through scope, source references, summaries and critical facts. Contracts give components a shared data shape; they do not authenticate users.

[ 02 ]

C1 · SQLite kalıcı hafızaC1 · SQLite persistent memory

Python 3.12 ve SQLite ile kaynak içeriği özgün baytlarıyla tutulur. Kayıtlar, sıralı özetler, kritik olgular ve kararların birbirinin yerini alması saklanır. Atomik işlemler yarım yazımların tutarsızlık üretmesini önlemeyi amaçlar.Python 3.12 and SQLite preserve original source bytes, records, ordered summaries, critical facts and supersession. Atomic transactions protect against inconsistent partial writes.

[ 03 ]

C1.1 · Bütünlük ve uyumlulukC1.1 · Integrity and compatibility

Okuma ve yazmada SHA-256 kontrolü yapılır. Beklenen şemayla uyuşmayan veritabanları reddedilir; otomatik onarım veya migrasyon yapılmaz. Bayt bütünlüğü, kaynağın güvenilir veya özetin doğru olduğunu kanıtlamaz.SHA-256 checks run on reads and writes. Incompatible database schemas are rejected without automatic repair or migration. Byte integrity does not establish source authenticity or summary accuracy.

[ 04 ]

Henüz hangi işleri yapmıyor?What remains outside this layer?

Bu depolama katmanı anlamsal arama, embedding, otomatik özetleme veya projeye özel bağlam oluşturma sistemi değildir. Bu işlevler için ayrı erişim ve işleme katmanları gerekiyor.Storage is not semantic search, embeddings, automatic summarisation or project-aware context building. Those features require separate retrieval and processing layers.
