[ 01 / BUGÜNTODAY ]

Bugün çalışan temel parçalarThe foundations implemented today

JARVIS şu anda geliştirilmekte olan bir ajan çekirdeği. Hafıza, model bağlantısı ve izin kontrolleri uygulandı; herkese açık, kullanıma hazır bir asistan olarak sunulmuyor.JARVIS is an agent core under development. Memory, model access and permission checks are implemented; it is not offered as a ready-to-use public assistant.

Kaynağıyla saklanan hafızaMemory with source history

Kayıtları, özetleri ve kritik bilgileri SQLite üzerinde kapsamları ve özgün kaynaklarıyla saklayan temel.A SQLite foundation that stores records, summaries and critical facts with their scopes and original sources.

İzin kontrollü okumaPermission-controlled reads

Bir görev yalnız izin verilen kapsamdaki kaydı okuyabilir. Model sağlayıcısına aktarım için ayrıca izin gerekir.A task may read only an authorised record within its scope. Sharing it with a model provider requires a separate grant.

Sınırlı ajan döngüsüA bounded agent loop

Model bir son yanıt veya hafıza okuma önerisi üretir. Döngü çağrı sayısı, veri boyutu ve süre sınırlarıyla çalışır.The model produces a final answer or proposes a memory read. The loop applies limits to calls, data size and duration.

Sırada inceleme varReview comes next

Uygulanan döngü bağımsız güvenlik incelemesi bekliyor. Projeye özel arama ve çok cihazlı koordinasyon sonraki hedefler.The implemented loop awaits independent security review. Project-aware search and multi-device coordination are future goals.

[ 02 / ÖRNEK AKIŞEXAMPLE FLOW ]

Bir hafıza okuması nasıl ilerliyor?How does a memory read work?

Aşağıdaki senaryo, mevcut bileşenlerin görevini açıklayan temsili bir örnektir; canlı demo veya gerçek çalıştırma çıktısı değildir.The scenario below illustrates the role of the current components. It is not a live demo or an actual execution transcript.

  1. GörevTask

    “Bu proje için kaydettiğim kararı özetle.” Güvenilir uygulama kodu görev kapsamını ve okunabilecek kayıt kimliğini belirler.“Summarise the decision I saved for this project.” Trusted application code defines the task scope and permitted record ID.

  2. ÖneriProposal

    Model, belirli bir kayıt için memory.read çağrısı önerir. İzinleri model belirlemez.The model proposes memory.read for a specific record. The model does not set permissions.

  3. KontrolCheck

    Araç, kapsam, kayıt ve aktarım izinleri kontrol edilir. İzin varsa kayıt ve kaynak bütünlüğü doğrulanır; yoksa görev reddedilir.Tool, scope, record and export grants are checked. With permission, the record and source integrity are validated; otherwise the task is denied.

  4. YanıtAnswer

    İzinli sonuç modele veri olarak verilir; kalan çağrı ve süre bütçesi içinde son yanıt istenir.The authorised result is supplied to the model as data, and a final answer is requested within the remaining call and time budget.
